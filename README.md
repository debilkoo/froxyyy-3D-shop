# FROXYYY 3D Shop

Moderný frontend pre FROXYYY — slovenský shop s 3D tlačenými gaming doplnkami.

## Stav
- responzívny moderný storefront
- kategórie produktov
- košík s množstvami a localStorage
- vlastná kľúčenka
- demo checkout
